## 🛒 智能电商客服

**场景**：电商平台售后客服，自动处理退换货咨询并分流。

```
用户提问 → 意图识别 →
  ├── 订单查询 → 子流程查询
  ├── 客户投诉 → 知识库检索(退换货规则) → 判断处理方式
  ├── 商品推荐 → 知识库检索 → 推荐匹配
  └── 闲聊 → LLM(豆包1.8深度思考) → 友好回复
```

- **Workflow 节点**：主流程 + 3 个子流程（订单/投诉/推荐）
- **知识库**：退换货政策（7天无理由、退款机制、质量问题处理）
- **模型**：意图识别(豆包1.6) + 闲聊(豆包1.8深度思考)
- **人格**：ESFJ — 友好、耐心、专业

[→ 查看完整配置](https://github.com/qingqing0012/coze-ecommerce-support)

## 🎯 职涯·模拟面试官

**场景**：根据 JD 和简历，自动生成结构化面试题，模拟真实面试。

```
输入岗位JD + 求职者简历 →
  分析岗位目标与侧重点 →
  分析简历匹配度/优缺点 →
  生成面试题：
    ├── 4 个基本问题（背景挖掘）
    ├── 3 个深度问题（压力面试）
    └── 1 个价值观问题
  → 输出完整面试报告（含参考答案）
```

- **人格**：INTJ — 严谨、结构化、10年HR经验
- **能力**：JD解析、简历分析、压力面试设计、价值观评估
- **输出**：完整报告格式（岗位分析 + 简历分析 + 面试题）

[→ 查看完整配置](https://github.com/qingqing0012/coze-career-interviewer)

## 📝 智能标书写作助手

**场景**：企业招投标，根据项目需求自动生成专业化标书。

## ⚖️ 合同审阅助手

**场景**：法务/商务合同签署前的智能审核，识别风险点并给出修改建议。

```
输入合同文本 →
  条款逐条分析 →
  风险识别：
    ├── 商业风险（付款、违约、责任）
    ├── 法律风险（管辖、仲裁、效力）
    └── 其他风险（数据、知产）
  → 输出：问题 → 分析 → 修改意见
```

- **输出格式**：严格的「问题 → 分析 → 修改建议」框架
- **能力**：法律知识 + 案例辅助说明
- **限制**：只讨论合同相关内容

[→ 查看完整配置](https://github.com/qingqing0012/coze-contract-reviewer-assistant)
